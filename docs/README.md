# Imperium Scan - Quantum Explorer

Explorer per Imperium Chain, progettato per l'era quantistica 2030.

## Tecnologie
- Frontend: HTML5 + CSS3 + JS
- Backend: Node.js + Express
- RPC: Imperium Chain (Chain ID 9819)

## Deploy
- Frontend: Vercel
- Backend: VPS

## Sviluppo
1. Clone il repository
2. `cd backend && npm install`
3. `npm run dev`
